## 🚀 خطوات التثبيت والتشغيل المحلي

### 1. تثبيت الحزم:
```bash
npm install
```

### 2. إعداد متغيرات البيئة:
قم بنسخ ملف `.env.example` إلى `.env` إذا لزم الأمر:
```bash
cp .env.example .env
```
المتغيرات المتاحة:
- `PORT`: المنفذ المخصص للتشغيل (افتراضياً `3000`).
- `APP_URL`: رابط التطبيق الأساسي (يُحقن تلقائياً).

### 3. تشغيل خادم التطوير (Full-Stack Dev):
```bash
npm run dev
```
سيعمل التطبيق الكامل مع واجهة Express وVite على الرابط:
`http://localhost:3000`

## 🗄️ بنية قاعدة البيانات ونظام الحفظ

- يتم حفظ البيانات في ملف هيكلي دائم بصيغة JSON ضمن المسار:
  `data/restaurant_db.json`
- يحتوي على الجداول والعلاقات التالية:
  - `Settings`: إعدادات المطعم، الاسم التجاري، الهاتف، الواتساب، مواعيد العمل، مناطق التوصيل.
  - `Categories`: تصنيفات الأطعمة والترتيب وحالة التفعيل.
  - `Products`: الأصناف، الأسعار، الصور، الأحجام (`sizes`)، الإضافات (`extras`)، السعرات، وحالة التوفر.
  - `Orders`: الطلبات المحفوظة مع أرقامها الفريدة (`ITL-XXXX`)، بيانات العميل، طريقة الدفع، وحالة التوصيل.
  - `adminTokens`: جلسات مدراء المطعم المصرح لهم.
- عمليات الحفظ تتم بشكل ذري وآمن لمنع تضارب البيانات أثناء التعديل أو الطلب.
